Reduce image size online to make a photo or picture smaller for uploads, email, forms, documents, and sharing. Squishyfile works in your browser, so your files stay on your device.

## Quick Steps

1. Choose an image from your device or drag it into the upload area.
2. Select an output format if you want to change it.
3. Choose a quality level: 40%, 60%, 75%, 85%, or 95%.
4. Set a smaller width if the image is still too large.
5. Download the smaller image and check that it meets your size requirement.

## When to Use This Image Size Reducer

Use this tool when an image is too large to upload, attach, submit, or share. It is useful for online forms, job applications, school portals, document uploads, email attachments, profile photos, and websites that have file size limits.

Reducing image size can mean compressing the file, resizing the image dimensions, or both. If you need a smaller file quickly, start with balanced quality and reduce the width when the original image is very large.

## File Size and Upload Tips

If a website asks for an image under a specific limit, download the result and check the final file size before uploading it.

For images with text, IDs, receipts, screenshots, or documents, do not reduce the quality too much. The file should be smaller, but names, numbers, edges, and important details should still be readable.
