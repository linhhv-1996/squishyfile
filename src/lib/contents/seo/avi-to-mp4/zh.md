## AVI 影片在現代裝置上失效的原因

AVI 是目前仍在使用的最古老影片容器格式之一。舊 Windows 電腦、早期數位相機、監視器錄影和舊版擷取軟體的檔案，通常都是 AVI 格式。AVI 格式本身沒有問題 — AVI 檔案可以包含畫質很好的影片 — 但這些檔案內部的 codec 常常不受現代手機、瀏覽器和應用程式支援。

這就是 AVI 相容性問題的核心。AVI 是容器，不是 codec。一個檔案可以有 .avi 副檔名，但內部仍然使用 Xvid、DivX、Cinepak、Indeo 或其他幾十種舊 codec，而現代裝置並不原生支援這些格式。MP4 — 特別是使用 H.264 編碼的 — 幾乎所有現代裝置和平台都能讀取。將 AVI 轉成 MP4，通常就是讓舊影片重新可用的必要步驟。

Squishyfile 在瀏覽器中使用 WebAssembly 和 FFmpeg 將 AVI 轉成 MP4。檔案在你的裝置上處理，不會上傳到伺服器，不需要帳號，轉出的 MP4 也沒有浮水印。

## 什麼時候應該轉換

不是每個 AVI 都需要轉換。如果你在外接硬碟存影片並用 VLC 播放，AVI 就夠用了。但在這些情況下，MP4 明顯是更好的選擇：

- AVI 影片無法在 iPhone、Android 或智慧電視上開啟
- 上傳到 YouTube、Google 雲端硬碟或其他平台時被拒絕
- 你想透過 Email 或通訊軟體傳送影片，不希望對方開不了
- 剪輯軟體開啟 AVI 後沒有音訊、出現綠色畫面或 codec 錯誤
- 你想把舊家庭錄影分享給家人，但他們的裝置沒有支援舊 codec 的播放器

最後這個情況在 2000 年代的 AVI 檔案特別常見。用 DivX 或 Xvid 編碼的影片在 VLC 可以播放，但在新系統的 QuickTime、Windows Media Player 或任何手機 App 中卻播不了。使用 H.264 的 MP4 可以避免這些問題。

## AVI 和 MP4 實際上有什麼差別

| | AVI | MP4 |
|---|---|---|
| 典型 codec | Xvid、DivX、Cinepak 等舊 codec | H.264（最常見）、H.265 |
| 手機支援 | 通常需要額外安裝 App | iOS 和 Android 原生支援 |
| 社群平台 | 常常被拒絕 | 廣泛接受 |
| 檔案大小 | 同畫質下較大 | 同畫質下更有效率 |
| 剪輯軟體匯入 | 支援不穩定 | 大多數軟體可靠支援 |

AVI 轉 MP4 不只是換容器 — 大多數情況下會把影片從舊 codec 重新編碼為 H.264。這就是為什麼轉換後的 MP4 能在 AVI 原本無法使用的環境中正常播放。

## 大型檔案和舊 codec 的處理

舊相機和擷取卡的 AVI 檔案通常很大，壓縮程度低或沒有壓縮，使用的 codec 就連 FFmpeg 也需要時間處理。這個工具在現代手機瀏覽器上可以使用，但對於大型或有問題的 AVI，桌上型電腦瀏覽器更穩定更快。

手機轉換變慢或卡住時，改用電腦瀏覽器再試。轉檔期間保持分頁開啟，不要讓裝置進入睡眠。

如果原始 AVI 在任何播放器中都無法開啟，檔案可能已損壞，或使用了瀏覽器引擎無法讀取的 codec。請先確認來源檔案 — 無法開啟的檔案也無法轉換。
