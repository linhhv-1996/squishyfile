## เมื่อไฟล์ AVI ใช้งานไม่ได้บนอุปกรณ์สมัยใหม่

AVI เป็นหนึ่งในรูปแบบคอนเทนเนอร์วิดีโอที่เก่าแก่ที่สุดที่ยังคงใช้งานอยู่ ไฟล์จากคอมพิวเตอร์ Windows รุ่นเก่า กล้องดิจิทัลรุ่นแรก ๆ การบันทึกกล้องวงจรปิด และซอฟต์แวร์จับภาพเก่ามักอยู่ในรูปแบบ AVI ตัวรูปแบบเองไม่ได้มีปัญหา — ไฟล์ AVI อาจมีวิดีโอที่ดีมากอยู่ภายใน แต่โค้ดภายในไฟล์เหล่านั้นมักไม่รองรับบนมือถือ เบราว์เซอร์ และแอปสมัยใหม่

นี่คือปัญหาหลักของความเข้ากันได้ของ AVI AVI เป็นคอนเทนเนอร์ ไม่ใช่โค้ด ไฟล์อาจมีนามสกุล .avi แต่ยังคงใช้ Xvid, DivX, Cinepak, Indeo หรือโค้ดเก่าอื่น ๆ อีกหลายสิบตัวที่อุปกรณ์ปัจจุบันไม่รองรับโดยตรง MP4 โดยเฉพาะที่ใช้การเข้ารหัส H.264 รองรับได้โดยแทบทุกอุปกรณ์และแพลตฟอร์มสมัยใหม่ การแปลง AVI เป็น MP4 มักเป็นสิ่งที่จำเป็นเพื่อให้วิดีโอเก่าสามารถใช้งานได้จริง

Squishyfile แปลง AVI เป็น MP4 ในเบราว์เซอร์ด้วย WebAssembly และ FFmpeg ไฟล์ถูกประมวลผลบนอุปกรณ์ของคุณ ไม่มีการอัปโหลดไปยังเซิร์ฟเวอร์ ไม่ต้องสมัครบัญชี ไม่ต้องติดตั้งโปรแกรม และไม่มีลายน้ำในไฟล์ที่แปลงแล้ว

## เมื่อไหรที่ควรแปลงเป็น MP4

ไม่ใช่ทุกไฟล์ AVI ต้องแปลง ถ้าเก็บวิดีโอในฮาร์ดไดรฟ์และดูด้วย VLC ก็ไม่จำเป็น แต่ในสถานการณ์เหล่านี้ MP4 ดีกว่าชัดเจน

- วิดีโอ AVI เปิดไม่ได้บน iPhone, Android หรือสมาร์ททีวี
- อัปโหลดไปยัง YouTube, Google Drive หรือแพลตฟอร์มอื่นที่ปฏิเสธ AVI
- ต้องการส่งวิดีโอทางอีเมลหรือแอปแชตโดยไม่ให้ผู้รับมีปัญหาเปิดไฟล์
- โปรแกรมตัดต่อเปิด AVI ได้แต่ไม่มีเสียง เฟรมสีเขียว หรือขึ้น error เรื่อง codec
- ต้องการแชร์วิดีโอเก่ากับครอบครัวที่อาจไม่มีโปรแกรมเล่นที่รองรับ codec เก่า

กรณีสุดท้ายพบบ่อยมากกับไฟล์ AVI จากช่วงปี 2000 ไฟล์ที่เข้ารหัสด้วย DivX หรือ Xvid อาจเล่นได้ใน VLC แต่เล่นไม่ได้ใน QuickTime, Windows Media Player บนระบบใหม่ หรือแอปมือถือใด ๆ MP4 ที่ใช้ H.264 หลีกเลี่ยงปัญหาเหล่านี้ทั้งหมด

## วิธีแปลงไฟล์ AVI เป็น MP4

**ขั้นตอนที่ 1 — เลือกไฟล์ AVI** ลากไฟล์ AVI เข้ามาในพื้นที่อัปโหลด หรือคลิกเพื่อเลือกไฟล์จากอุปกรณ์ของคุณ เครื่องมือนี้ทำงานกับไฟล์ที่บันทึกในเครื่อง ไม่รองรับการดาวน์โหลดจาก URL

**ขั้นตอนที่ 2 — ยืนยันรูปแบบไฟล์ปลายทางเป็น MP4** หน้านี้แปลงเป็น MP4 ไว้แล้วโดยค่าเริ่มต้น MP4 ให้ความเข้ากันได้กว้างที่สุดสำหรับไฟล์ที่แปลงแล้ว

**ขั้นตอนที่ 3 — แปลงและดาวน์โหลด** เปิดแท็บเบราว์เซอร์ไว้ระหว่างที่ไฟล์กำลังถูกประมวลผล ดาวน์โหลด MP4 เมื่อการแปลงเสร็จสิ้น

## AVI และ MP4 ต่างกันอย่างไรจริง ๆ

| | AVI | MP4 |
|---|---|---|
| โค้ดทั่วไป | Xvid, DivX, Cinepak หรือโค้ดเก่าอื่น ๆ | H.264 (พบมากที่สุด), H.265 |
| รองรับบนมือถือ | มักต้องติดตั้งแอปเพิ่ม | รองรับโดยตรงบน iOS และ Android |
| แพลตฟอร์มโซเชียล | มักถูกปฏิเสธ | รองรับกว้างขวาง |
| ขนาดไฟล์ | ใหญ่กว่าเมื่อคุณภาพเท่ากัน | ประหยัดกว่าในคุณภาพเดียวกัน |
| นำเข้าโปรแกรมตัดต่อ | รองรับไม่สม่ำเสมอ | รองรับได้ในแอปส่วนใหญ่ |

การแปลง AVI เป็น MP4 ไม่ใช่แค่การเปลี่ยนคอนเทนเนอร์ — ส่วนใหญ่จะมีการเข้ารหัสวิดีโอใหม่จากโค้ดเก่าเป็น H.264 นี่คือเหตุผลที่ไฟล์ที่แปลงแล้วทำงานได้ในสภาพแวดล้อมที่ AVI ต้นฉบับทำไม่ได้

## ไฟล์ขนาดใหญ่และโค้ดเก่าบนมือถือ

ไฟล์ AVI จากกล้องเก่าและการ์ดจับภาพมักมีขนาดใหญ่ บีบอัดน้อยหรือไม่บีบอัดเลย และใช้โค้ดที่แม้แต่ FFmpeg ก็ต้องใช้เวลาในการประมวลผล เครื่องมือนี้ทำงานในเบราว์เซอร์มือถือสมัยใหม่ได้ แต่สำหรับไฟล์ AVI ขนาดใหญ่หรือมีปัญหา เบราว์เซอร์บนคอมพิวเตอร์จะเสถียรและเร็วกว่า

ถ้าการแปลงช้าหรือค้างบนมือถือ ให้ลองใช้คอมพิวเตอร์แทน เปิดแท็บไว้และไม่ล็อกหน้าจอระหว่างประมวลผล

ถ้าไฟล์ AVI เปิดไม่ได้ในโปรแกรมเล่นวิดีโอใด ๆ ก่อนแปลง ไฟล์อาจเสียหายหรือใช้โค้ดที่เบราว์เซอร์อ่านไม่ได้ ตรวจสอบไฟล์ต้นฉบับก่อน — ไฟล์ที่เปิดไม่ได้ก็แปลงไม่ได้เช่นกัน
