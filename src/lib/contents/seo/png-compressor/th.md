## ควรใช้เครื่องมือย่อไฟล์ PNG เมื่อไหร่

ใช้เครื่องมือย่อไฟล์ PNG เมื่อต้องการลดขนาดไฟล์ของโลโก้ ไอคอน ภาพหน้าจอ กราฟิก UI ภาพประกอบเอกสาร หรือรูปที่มีพื้นหลังโปร่งใส โดยยังต้องการให้เส้น ตัวอักษร และขอบภาพดูคมชัดพอสำหรับการใช้งานจริง

PNG เหมาะกับภาพที่ต้องการความคมและ transparency แต่ไฟล์มักใหญ่กว่า JPG โดยเฉพาะภาพหน้าจอขนาดใหญ่ ไฟล์จากโปรแกรมออกแบบ หรือกราฟิกที่มีรายละเอียดจำนวนมาก การบีบอัด PNG ช่วยให้ไฟล์เบาลงก่อนนำไปใช้บนเว็บไซต์ แนบเอกสาร ส่งอีเมล อัปโหลดแบบฟอร์ม หรือส่งต่อให้ทีมงาน

ถ้ารูปของคุณเป็นภาพถ่ายจากมือถือ รูปสินค้า หรือภาพที่มีสีและรายละเอียดแบบภาพจริง หน้า [ย่อไฟล์ JPG](/th/jpg-compressor) อาจเหมาะกว่า หากต้องการบีบอัดหลายรูปแบบไฟล์ในที่เดียว ใช้หน้า [บีบอัดรูปภาพออนไลน์](/th/image-compressor) ได้

## ค่าที่แนะนำสำหรับการลดขนาด PNG

การลดขนาด PNG ไม่ควรดูแค่ไฟล์เล็กลงเท่าไหร่ แต่ควรดูด้วยว่าข้อความยังอ่านได้ ขอบยังคม และพื้นหลังโปร่งใสยังทำงานถูกต้องหรือไม่

| การใช้งาน | สิ่งที่ควรตรวจ | วิธีปรับที่แนะนำ |
|---|---|---|
| โลโก้หรือภาพแบรนด์ | ขอบโลโก้ สี และพื้นหลังโปร่งใส | บีบอัดแบบไม่หนักเกินไป และอย่าลดขนาดต่ำกว่าที่ใช้จริง |
| ไอคอนหรือปุ่ม UI | เส้นขอบและความคมในขนาดเล็ก | ลดไฟล์เบา ๆ; ลดความกว้างเมื่อไฟล์ต้นฉบับใหญ่เกินจำเป็น |
| ภาพหน้าจอ | ตัวอักษร เมนู ปุ่ม ตาราง | อย่าลด dimensions จนอ่านยาก |
| ภาพประกอบเอกสาร | รายละเอียด เส้น ลูกศร คำอธิบาย | ตรวจดูภาพในขนาดที่ใช้งานจริงก่อนส่งต่อ |
| กราฟิกบนเว็บไซต์ | น้ำหนักหน้าเว็บและความคม | บีบอัดก่อน แล้วลดความกว้างถ้ายังไฟล์ใหญ่ |
| ไฟล์สำหรับอัปโหลด | ขนาดไฟล์สุดท้าย | ใช้ทั้งการบีบอัดและลดความกว้างเพื่อให้ผ่านข้อจำกัด |

หลังบีบอัดควรเปิดดูไฟล์อย่างน้อยหนึ่งครั้ง โดยเฉพาะภาพที่มีตัวอักษร เส้นบาง หรือพื้นหลังโปร่งใส เพราะจุดเหล่านี้เป็นเหตุผลหลักที่ทำให้หลายคนเลือกใช้ PNG แทน JPG

## PNG เหมาะกับภาพโปร่งใส ตัวอักษร และเส้นคม

PNG เป็นรูปแบบไฟล์ที่เหมาะกับภาพกราฟิกมากกว่าภาพถ่ายทั่วไป จุดเด่นคือรองรับพื้นหลังโปร่งใส และมักแสดงข้อความ เส้นตรง ขอบไอคอน หรือพื้นที่สีเรียบได้คมกว่า JPG

ตัวอย่างภาพที่เหมาะกับ PNG ได้แก่:

- โลโก้ที่ต้องวางบนพื้นหลังหลายสี
- ไอคอน ปุ่ม หรือภาพ UI
- ภาพหน้าจอของแอปหรือเว็บไซต์
- ภาพที่มีตัวอักษร ตาราง หรือเมนู
- กราฟิกประกอบบทความหรือคู่มือ
- สติกเกอร์ ลายน้ำ หรือรูปพื้นหลังโปร่งใส

ถ้าเป็นภาพถ่าย เช่น รูปคน อาหาร สินค้า หรือวิวธรรมชาติ ไฟล์ JPG มักเล็กกว่าและเหมาะกว่าในคุณภาพที่ใกล้เคียงกัน

## วิธีลดขนาด PNG โดยไม่เสียรายละเอียดสำคัญ

เริ่มจากการบีบอัดระดับพอดี แล้วดูผลลัพธ์จริงก่อนลดหนักขึ้น สำหรับโลโก้และไอคอน ให้ดูขอบภาพและความโปร่งใส สำหรับภาพหน้าจอ ให้ดูว่าตัวอักษร เมนู และเส้นเล็ก ๆ ยังอ่านง่ายหรือไม่

ถ้าไฟล์ยังใหญ่เกินไป ให้ตรวจขนาดภาพจริง หลายไฟล์ PNG ถูก export ใหญ่กว่าที่ใช้จริงมาก เช่น ไอคอนที่แสดงบนเว็บเพียง 128px แต่ไฟล์ต้นฉบับกว้างหลายพันพิกเซล การลดความกว้างให้ใกล้กับขนาดแสดงผลจริงจะช่วยลดไฟล์ได้มาก

อย่าบีบอัดไฟล์เดิมซ้ำหลายรอบโดยไม่จำเป็น เพราะรายละเอียดอาจค่อย ๆ เสียไป หากต้องทำหลายเวอร์ชัน ควรเริ่มจากไฟล์ต้นฉบับเสมอ

## PNG กับ JPG ควรเลือกแบบไหน

เลือก PNG เมื่อภาพต้องการพื้นหลังโปร่งใส ตัวอักษรคม เส้นชัด หรือเป็นภาพหน้าจอและกราฟิก UI เลือก JPG เมื่อภาพเป็นภาพถ่าย รูปสินค้า ภาพจากมือถือ หรือรูปที่มีสีและรายละเอียดแบบธรรมชาติ

สำหรับเว็บไซต์ ควรใช้ PNG เฉพาะจุดที่จำเป็น เช่น โลโก้ ไอคอน ภาพโปร่งใส และ screenshot ส่วนภาพถ่ายขนาดใหญ่ควรใช้ JPG เพื่อให้หน้าเว็บเบาลง

ถ้าเป้าหมายหลักคือทำให้ไฟล์เล็กลงเพื่อผ่านข้อจำกัดการอัปโหลด ส่งอีเมล หรือแนบเอกสาร หน้า [ลดขนาดรูปภาพ](/th/reduce-image-size) อาจตรงกับงานมากกว่า
