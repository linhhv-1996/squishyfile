## 什麼時候適合使用PNG壓縮

PNG壓縮適合用在需要保留清楚邊緣、文字細節或透明背景的圖片，例如 Logo、Icon、螢幕截圖、UI 圖片、圖表、貼圖、浮水印和設計素材。PNG 可以讓線條與文字看起來比較乾淨，也能保留透明背景，但檔案容量有時會比預期更大。

如果 PNG 檔案太大，可能會造成網站載入變慢、Email 附件太大、表單無法上傳，或設計素材不方便傳送。透過 PNG壓縮，可以在保留可用畫質的情況下縮小 PNG 檔案，讓圖片更適合網站、文件、簡報、設計交付和日常分享。

這個頁面適合處理 PNG 圖片。如果你要壓縮照片、商品照或手機拍攝的圖片，通常 [JPG壓縮工具](/zh/jpg-compressor) 會更適合。若要一次處理 JPG、PNG、WebP、AVIF 等不同格式，可以使用 [線上圖片壓縮工具](/zh/image-compressor)。

## PNG壓縮設定建議

壓縮 PNG 時，不只要看檔案變小多少，也要確認文字是否清楚、邊緣是否乾淨、透明背景是否正常。

| 使用情境 | 需要檢查 | 建議做法 |
|---|---|---|
| Logo 或品牌圖 | 邊緣、透明背景、顏色 | 品質不要壓太低，避免邊緣變粗糙 |
| Icon 或 UI 元件 | 小尺寸是否清楚、透明區域 | 輕量壓縮；原圖過大時再縮小寬度 |
| 螢幕截圖 | 文字、按鈕、表格是否可讀 | 不要縮到文字看不清楚 |
| 文件或教學圖片 | 標註、細線、介面細節 | 壓縮後用實際顯示尺寸檢查 |
| 網站圖片 | 頁面速度與視覺品質 | 先壓縮，再依實際顯示寬度調整尺寸 |
| 表單或上傳限制 | 最終檔案大小 | 搭配壓縮與寬度調整，讓檔案低於限制 |

如果圖片是 Logo、截圖或含文字的 PNG，壓縮後最好放大看一次。檔案變小很重要，但文字、線條和透明邊緣仍然要能正常使用。

## PNG適合透明背景、文字與清楚線條

PNG 的優勢是支援透明背景，也比較適合保存文字、線條、扁平色塊和圖形邊緣。因此 PNG 常用在網站 Logo、Icon、App 介面、截圖、設計輸出、資訊圖表和透明圖片。

常見適合 PNG 的圖片包括：

- 透明背景 Logo
- 網站或 App Icon
- 含文字的螢幕截圖
- UI 介面圖片
- 教學文件中的圖解
- 貼圖、浮水印和透明素材

如果圖片主要是照片，例如人物、食物、風景、商品拍攝圖，PNG 通常不是最省容量的格式。這類圖片通常用 JPG/JPEG 會更容易得到較小的檔案。

## 如何縮小PNG檔案又保留重要細節

想縮小 PNG 檔案時，先從適度壓縮開始。對 Logo、Icon 和截圖來說，最重要的是邊緣不要糊、文字不要變難讀、透明背景不要出問題。

如果壓縮後檔案仍然太大，下一步應該檢查圖片尺寸。很多 PNG 是從設計工具或高解析螢幕輸出，實際使用時可能不需要那麼大的寬度。例如網站上顯示 300px 的圖示，不需要保留成 2000px 寬的 PNG。

但不要為了縮小檔案而過度降低尺寸。螢幕截圖、教學圖片、表格截圖和 UI 圖片如果縮太小，使用者會看不清楚內容。

## PNG和JPG該怎麼選

PNG 適合需要透明背景、文字清楚、邊緣銳利的圖片。JPG 適合照片、商品圖、人物照、風景圖和色彩豐富的影像。

在網站上，可以把 Logo、Icon、截圖和透明素材保留為 PNG；把照片、商品照和大型視覺圖改用 JPG。這樣通常能讓頁面更輕，同時保留該清楚的地方。

如果你的目標不是指定 PNG，而是讓圖片符合上傳限制、Email 附件限制或文件系統限制，可以使用 [圖片縮小工具](/zh/reduce-image-size)。
