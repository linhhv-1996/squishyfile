## 商品ラベルや在庫管理に使えるバーコード作成ツール

商品ラベル、在庫管理、SKU、シリアル番号、発送ラベル、倉庫ラベル、社内管理コードなどに使えるバーコードをオンラインで作成できます。入力した値はブラウザ上でバーコード化されるため、ソフトのインストールやアカウント登録は不要です。

1つのバーコードをすぐに作成することも、複数の値からバーコードをまとめて作成することもできます。作成したバーコードはPNGまたはSVGでダウンロードでき、資料、ラベル印刷、商品画像、社内管理ファイルなどに利用できます。

## 作成できるバーコード形式

このバーコード作成ツールでは、商品ラベル、在庫ラベル、管理番号、シリアル番号、物流ラベルなどに使える1次元バーコードを作成できます。

| 形式 | 主な用途 |
|---|---|
| CODE 128 | SKU、在庫番号、管理コード、シリアル番号、注文番号など |
| CODE 39 | 英数字中心の短い管理ラベル |
| EAN-13 | 13桁の商品バーコード |
| EAN-8 | 8桁の短い商品コード |
| UPC-A | 12桁の米国向け商品コード |
| JAN | 日本の商品バーコード |
| ITF-14 | 段ボール、外箱、物流単位のコード |

社内管理用のバーコードを作成する場合は、まずCODE 128を選ぶと扱いやすいです。商品流通用のEAN、UPC、JANなどは、決められた桁数の数字が必要です。

## バーコードを作成する方法

1. **単一バーコード**または**一括バーコード**を選びます。
2. SKU、商品番号、在庫番号、シリアル番号、管理コードなどの値を入力します。
3. 用途に合うバーコード形式を選択します。
4. 必要に応じて高さ、線の太さ、表示テキストを調整します。
5. バーコードを作成し、PNGまたはSVGでダウンロードします。

一括バーコード作成は、商品ラベル、在庫ラベル、倉庫管理用ラベル、シリアル番号ラベルをまとめて準備したいときに便利です。スプレッドシートで値を整理してから作成すると、重複や入力ミスも確認しやすくなります。

## どのバーコード形式を選べばいい？

一般的な管理用バーコードなら、**CODE 128** がおすすめです。数字、英字、よく使われる記号に対応しているため、SKU、在庫コード、注文番号、シリアル番号、社内管理番号など幅広い用途で使えます。

**CODE 39** は、英数字中心の短いコードに向いています。ただし、対応できる文字の範囲はCODE 128より限られるため、迷った場合はCODE 128のほうが使いやすいことが多いです。

商品バーコードを作成する場合は、手元にあるコードの種類に合わせて **EAN-13**、**UPC-A**、**JAN** などを選びます。これらの形式は桁数が決まっており、文字を含む値や桁数が違う値は使用できません。

外箱、段ボール、物流単位のコードには **ITF-14** が使われることがあります。

## 商品バーコードと正式なコード登録について

このツールは、入力した値からバーコード画像を作成するツールです。EAN、UPC、JANなどの商品コードを新しく発行したり、公式に登録したりするものではありません。

店舗、ECモール、取引先、物流システムで使う商品バーコードを作成する場合は、あらかじめ正式に割り当てられた商品コードを用意してください。そのコードをもとに、正しい形式でバーコード画像を作成します。

社内用のSKU、在庫番号、シリアル番号、管理コードであれば、CODE 128を使うと柔軟に作成できます。

## PNGとSVGの使い分け

**PNG** は、書類、スプレッドシート、簡単なラベル印刷、資料への貼り付けに使いやすい画像形式です。すぐに使えるバーコード画像が必要な場合に向いています。

**SVG** は、拡大しても劣化しにくいベクター形式です。デザインソフト、印刷用データ、ラベルレイアウト、パッケージ案などで、きれいなバーコードを使いたい場合に適しています。

ダウンロード後にバーコードを無理に引き伸ばすと、読み取りにくくなることがあります。印刷する場合は、サイズ、線の太さ、余白、コントラストを確認してください。

## ブラウザ上で完結するプライベートなバーコード作成

バーコードには、商品番号、在庫番号、顧客管理番号、注文番号、社内コードなどが含まれることがあります。Squishyfileでは、バーコード作成をブラウザ上で行うため、入力した値をサーバーへ送信しません。

外部に送信したくない商品データ、社内管理コード、在庫リストを扱う場合でも、手元のブラウザでバーコードを作成できます。

## よくある失敗と対処法

### 商品コードの桁数が合っていない

EAN-13とJANは13桁、UPC-Aは12桁、EAN-8は8桁の数字が必要です。桁数が違う場合や英字を含む場合は、CODE 128を選んでください。

### 数字専用の形式に文字を入れている

EAN、UPC、JAN、ITF-14は数字用のバーコード形式です。英字、スペース、記号を含む値を使いたい場合は、CODE 128またはCODE 39を選んでください。

### 用途に合わない形式を選んでいる

社内用の在庫番号やSKUには、CODE 128で十分な場合が多くあります。流通用の商品バーコードとは用途が違うため、必要な形式を確認してから作成してください。

### 印刷したバーコードが読み取りにくい

バーコードが小さすぎる、線が細すぎる、余白が足りない場合は、読み取りにくくなることがあります。小さなラベルに印刷する場合や、離れた距離から読み取る場合は、高さや線の太さを調整してください。

### 一括印刷前にテストしていない

バーコードを大量に印刷する前に、実際に使うスキャナーやスマートフォンアプリで読み取りテストを行ってください。サイズ、余白、印刷品質、入力値の間違いを事前に確認できます。
