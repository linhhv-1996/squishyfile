# バーコード作成｜無料オンラインバーコード生成ツール

商品ラベル、在庫管理、SKU、シリアル番号、発送用ラベルなどに使えるバーコードをオンラインで作成できます。入力した値はブラウザ上でバーコード化されるため、サーバーへアップロードされません。

1つのバーコードをすぐに作成することも、複数のバーコードをまとめて生成することもできます。作成したバーコードはPNGまたはSVGでダウンロードできます。

## このツールで作成できるバーコード

バーコード作成、バーコード生成、無料バーコード作成、バーコード画像作成などの用途に使えるシンプルなオンラインツールです。

| 形式 | 主な用途 |
|---|---|
| CODE 128 | SKU、在庫番号、管理コード、シリアル番号など |
| CODE 39 | 英数字中心の短い管理ラベル |
| EAN-13 | 13桁の商品バーコード |
| EAN-8 | 8桁の短い商品コード |
| UPC-A | 12桁の米国向け商品コード |
| JAN | 日本の商品バーコード |
| ITF-14 | 段ボール、外箱、物流単位のコード |

## バーコードの作成方法

1. **単一バーコード**または**一括バーコード**を選びます。
2. SKU、商品番号、在庫番号、シリアル番号などの値を入力します。
3. バーコード形式を選択します。
4. 高さ、線の太さ、表示テキストを調整します。
5. バーコードを生成し、PNGまたはSVGでダウンロードします。

複数の値をまとめて入力すれば、一括バーコード作成にも対応できます。商品ラベル、在庫ラベル、倉庫管理用ラベルをまとめて準備したいときに便利です。

## どのバーコード形式を選べばいい？

迷った場合は、まず **CODE 128** を選ぶのがおすすめです。数字だけでなく英字や一般的な記号にも対応し、SKU、在庫コード、社内管理番号など幅広い用途で使いやすい形式です。

商品バーコードを作成する場合は、コードの種類に合わせて **EAN-13**、**JAN**、**UPC-A** を選びます。これらは桁数が決まっているため、文字を含む値や桁数が違う値は使用できません。

日本向けの商品コードだけを作りたい場合は、専用ページの[JANコード作成](/ja/jan-code-generator)も利用できます。

## PNGとSVGの使い分け

**PNG**は、書類、スプレッドシート、簡単なラベル印刷に使いやすい画像形式です。すぐに貼り付けて使いたい場合に向いています。

**SVG**は、拡大しても劣化しないベクター形式です。デザインソフト、印刷用データ、ラベルレイアウトでバーコードをきれいに使いたい場合に適しています。

## ブラウザ上で完結するプライベートなバーコード生成

バーコードには、商品番号、在庫番号、顧客管理番号、社内コードなどが含まれることがあります。このツールはブラウザ上でバーコードを生成するため、入力した値をサーバーへ送信しません。アカウント登録も不要です。

## よくある失敗と対処法

### EAN-13、JAN、UPC-Aでエラーになる

EAN-13とJANは13桁、UPC-Aは12桁、EAN-8は8桁の数字が必要です。桁数が違う場合や英字を含む場合は、CODE 128を選んでください。

### 商品バーコードと社内管理バーコードを混同している

社内用の在庫番号やSKUならCODE 128で十分な場合が多いです。流通用の商品バーコードには、正式に割り当てられたJAN、EAN、UPCなどのコードを使用してください。

### 印刷したバーコードが読み取りにくい

線が細すぎる、サイズが小さすぎる、余白が足りない場合は読み取りにくくなります。高さや線の太さを調整し、印刷前にスキャンテストを行ってください。

## よくある質問

### 無料でバーコードを作成できますか？

はい。インストールやアカウント登録なしで、無料でバーコードを作成できます。

### 複数のバーコードをまとめて作れますか？

はい。一括バーコード作成モードを使うと、複数の値からまとめてバーコードを生成できます。

### 入力したデータはアップロードされますか？

いいえ。バーコード生成はブラウザ上で実行され、入力した値はサーバーへ送信されません。

### 商品バーコードも作成できますか？

はい。すでに正しい商品コードを持っている場合は、EAN-13、JAN、UPC-Aなどの形式でバーコード画像を作成できます。ただし、このツールは商品コードの登録や発行を行うものではありません。

### どの形式を選べばよいかわかりません

SKU、在庫番号、シリアル番号などの一般的な用途ならCODE 128がおすすめです。商品流通用のコードなら、必要な規格に合わせてEAN-13、JAN、UPC-Aを選んでください。
