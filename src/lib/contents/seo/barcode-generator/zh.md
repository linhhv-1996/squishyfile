## 免費線上條碼產生器，適合商品、庫存與 SKU

使用這個線上條碼產生器，可以製作商品條碼、庫存條碼、SKU、序號、出貨標籤與內部管理用條碼。條碼會直接在瀏覽器中產生，不需要安裝軟體，也不會把輸入內容上傳到伺服器。

你可以產生單一條碼，也可以從多個值批次建立條碼，並將結果下載為 PNG 或 SVG。PNG 適合快速使用，SVG 則適合需要縮放、排版或印刷的工作流程。

---

## 支援的條碼格式

這個工具可將文字或數字轉成一維條碼，適合用於商品標籤、庫存管理、內部追蹤、物流包裝與文件標示。

| 格式 | 適合用途 |
|---|---|
| CODE 128 | SKU、庫存編號、序號、訂單編號、一般文字與數字 |
| CODE 39 | 英文大寫字母與數字的短標籤 |
| EAN-13 | 13 位數商品條碼 |
| EAN-8 | 8 位數短商品碼 |
| UPC-A | 12 位數美國商品條碼 |
| JAN | 日本商品條碼 |
| ITF-14 | 外箱、物流箱與包裝單位 |

如果只是製作一般管理用條碼，CODE 128 通常是最彈性的選擇。若要製作正式商品流通條碼，則應使用你已經取得的 EAN、UPC、JAN 或其他指定編號。

---

## 如何製作條碼

1. 選擇**單一條碼**或**批次條碼**。
2. 輸入條碼內容，例如 SKU、商品編號、庫存碼、序號或內部追蹤碼。
3. 選擇條碼格式。
4. 視需要調整高度、線條寬度與是否顯示文字。
5. 產生條碼，並下載 PNG 或 SVG。

如果需要一次建立多個條碼，可以使用批次模式。這對商品標籤、庫存標籤、倉儲標籤、序號條碼或大量內部管理碼特別實用。

---

## 該選哪一種條碼格式？

選擇 **CODE 128**，適合 SKU、庫存編號、序號、訂單編號、內部追蹤代碼與一般文字數字。它支援的內容較彈性，適合多數內部管理場景。

選擇 **CODE 39**，適合較短的英文大寫字母與數字標籤。不過它支援的字元範圍比 CODE 128 少，若不確定要選哪個格式，CODE 128 通常更好用。

選擇 **EAN-13**、**UPC-A** 或 **JAN**，適合你已經擁有正式商品編號的情況。這些格式通常只能使用固定長度的數字，不適合任意文字。

選擇 **ITF-14**，適合外箱、物流箱或包裝單位的條碼需求。

---

## 商品條碼與正式編號註冊

這個工具會根據你輸入的內容產生條碼圖片，但不會發行、註冊或分配正式商品編號。

如果條碼需要用於商店、通路、供應鏈或電商平台，你應該先取得正確的 EAN、UPC、JAN 或其他正式商品編號，再使用對應格式產生條碼圖片。

如果只是用於內部庫存、SKU、序號、倉儲管理或內部追蹤，通常可以使用 CODE 128 來製作條碼。

---

## PNG 和 SVG 要怎麼選？

選擇 **PNG**，適合快速貼到文件、試算表、簡易標籤、出貨單或一般列印使用。

選擇 **SVG**，適合需要放大、排版或交給設計軟體使用的情況。SVG 是向量格式，放大後仍能保持清晰，適合印刷用標籤、包裝版面與專業設計流程。

下載後請避免任意拉伸條碼，因為比例變形可能會影響掃描結果。

## 在瀏覽器中私密產生條碼

條碼內容可能包含商品編號、庫存代碼、序號、訂單編號、客戶參考碼或內部管理資訊。Squishyfile 會直接在瀏覽器中產生條碼，不需要註冊帳號，也不會把輸入內容送到伺服器。

這種方式適合處理工作用資料、內部管理碼、尚未公開的商品資訊或不想上傳到外部伺服器的條碼內容。

## 常見錯誤與解決方式

### EAN-13、JAN、UPC-A 無法產生

EAN-13 和 JAN 需要 13 位數，UPC-A 需要 12 位數，EAN-8 需要 8 位數。如果你的內容包含文字、符號，或位數不符合，請改用 CODE 128。

### 在只能使用數字的格式中輸入文字

EAN、UPC、JAN 和 ITF-14 是數字用的條碼格式。如果要使用英文字母、空格或符號，請選擇 CODE 128 或 CODE 39。

### 選到不適合用途的條碼格式

內部 SKU、庫存編號、序號通常可以使用 CODE 128。正式商品流通條碼則應使用已分配的 EAN、UPC、JAN 或其他指定編號。

### 條碼列印後不好掃描

條碼太小、線條太細或留白不足，都可能影響掃描。若要印在小標籤上，或需要從較遠距離掃描，請調整高度、線寬與留白，並在正式列印前測試。

### 批次列印前沒有先測試

大量列印條碼前，建議先用實際會使用的掃描器或手機 App 測試。這可以提前發現尺寸、格式、對比、列印品質或輸入值錯誤等問題。
