# 條碼產生器｜免費線上製作條碼

使用這個免費線上條碼產生器，可以快速製作商品條碼、庫存條碼、SKU、序號、出貨標籤與內部管理用條碼。條碼會直接在瀏覽器中產生，輸入的內容不會上傳到伺服器。

你可以產生單一條碼，也可以批次建立多個條碼，並下載為 PNG 或 SVG 檔案。

## 可以產生哪些條碼？

這個工具適合「條碼產生器」、「條碼生成器」、「免費條碼產生器」、「線上條碼產生器」等常見需求，也支援一維條碼與批次條碼產生。

| 格式 | 適合用途 |
|---|---|
| CODE 128 | SKU、庫存編號、序號、一般文字與數字 |
| CODE 39 | 英文大寫字母與數字的短標籤 |
| EAN-13 | 13 位數商品條碼 |
| EAN-8 | 8 位數短商品碼 |
| UPC-A | 12 位數美國商品條碼 |
| JAN | 日本商品條碼 |
| ITF-14 | 外箱、物流箱與包裝單位 |

## 如何製作條碼

1. 選擇**單一條碼**或**批次條碼**。
2. 輸入條碼內容，例如 SKU、商品編號、庫存碼或序號。
3. 選擇條碼格式。
4. 調整高度、線條寬度與是否顯示文字。
5. 產生條碼，並下載 PNG 或 SVG。

如果需要一次建立多個條碼，可以使用批次模式。這對商品標籤、庫存管理、倉儲標籤或大量序號條碼特別實用。

## 該選哪一種條碼格式？

如果只是要製作一般管理用條碼，建議先使用 **CODE 128**。它支援數字、英文字母與多數常見字元，適合 SKU、庫存編號、序號與內部追蹤代碼。

如果是商品流通條碼，請依照你的編碼類型選擇 **EAN-13**、**UPC-A** 或 **JAN**。這些格式通常只能使用固定長度的數字，因此輸入錯誤時會無法產生條碼。

外箱或物流包裝常見需求則可以使用 **ITF-14**。

## PNG 和 SVG 要怎麼選？

選擇 **PNG**，適合快速貼到文件、試算表、簡易標籤或一般列印使用。

選擇 **SVG**，適合需要放大、排版或交給設計軟體使用的情況。SVG 是向量格式，放大後仍能保持清晰。

## 在瀏覽器中私密產生條碼

條碼內容可能包含商品編號、庫存代碼、序號或內部管理資訊。這個工具在瀏覽器中直接產生條碼，不需要註冊帳號，也不會把輸入內容送到伺服器，適合處理工作用與內部管理用資料。

## 常見錯誤與解決方式

### EAN-13、JAN、UPC-A 無法產生

EAN-13 和 JAN 需要 13 位數，UPC-A 需要 12 位數，EAN-8 需要 8 位數。如果你的內容包含文字或位數不符合，請改用 CODE 128。

### 商品條碼和內部條碼用途不同

內部 SKU、庫存碼、序號通常可以用 CODE 128。正式商品流通條碼則需要使用已分配的 EAN、UPC 或 JAN 編號。

### 條碼列印後不好掃描

條碼太小、線條太細或留白不足都可能影響掃描。列印前請調整高度與線寬，並用實際掃描器或手機測試。

## 常見問題

### 這個條碼產生器是免費的嗎？

是。你可以免費線上製作條碼，不需要安裝軟體或建立帳號。

### 可以批次產生多個條碼嗎？

可以。使用批次條碼模式即可一次建立多個條碼並下載。

### 輸入的條碼內容會被上傳嗎？

不會。條碼是在你的瀏覽器中產生，輸入內容會留在你的裝置上。

### 可以製作商品條碼嗎？

可以，只要你已經有正確的商品編號，就能用 EAN-13、UPC-A 或 JAN 產生條碼圖片。本工具不提供商品編號註冊服務。

### 不知道格式要選哪個怎麼辦？

一般 SKU、庫存編號、序號可選 CODE 128。零售商品碼請依需求選 EAN-13、UPC-A 或 JAN。
