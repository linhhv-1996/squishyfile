## Supported Barcode Formats

This tool creates 1D barcodes for products, documents, labels, warehouse workflows and internal systems.

| Format | Best for |
|---|---|
| CODE 128 | SKUs, inventory codes, serial numbers, order IDs and general text |
| CODE 39 | Short uppercase letters and numbers |
| EAN-13 | 13-digit retail product codes |
| EAN-8 | Short 8-digit retail codes |
| UPC-A | 12-digit US retail product codes |
| JAN | Japanese retail product codes |
| ITF-14 | Cartons, shipping units and outer packaging |

For most internal labels, CODE 128 is the best default because it accepts numbers, letters and many common characters. Retail formats such as EAN-13, UPC-A and JAN are stricter because they require fixed-length numeric values.

## Choosing the Right Barcode Type

Choose **CODE 128** for flexible internal use: SKUs, inventory IDs, asset tags, serial numbers, order references and warehouse labels. It is usually the safest choice when the value contains letters, numbers or mixed characters.

Choose **CODE 39** for simple short codes made from uppercase letters and numbers. It is easy to use, but less flexible than CODE 128.

Choose **EAN-13**, **UPC-A** or **JAN** only when you already have a valid retail product number in that format. These barcode types are not meant for arbitrary text or internal notes.

Choose **ITF-14** for cartons, outer cases and logistics units where a package-level code is needed.

## Common Mistakes to Avoid

### Using the wrong length for retail codes

EAN-13 and JAN require 13 digits. UPC-A requires 12 digits. EAN-8 requires 8 digits. If your value has a different length, use CODE 128 instead.

### Adding letters to numeric-only formats

EAN, UPC, JAN and ITF-14 are numeric barcode formats. If your value contains letters, spaces or symbols, choose CODE 128 or CODE 39.

### Choosing a retail barcode for internal tracking

Internal SKUs, inventory numbers and serial numbers usually do not need EAN or UPC. CODE 128 is often more practical for internal tracking because it supports more value types.

### Making the barcode too small

A barcode that is too small, too narrow or printed without enough quiet space may be hard to scan. Increase the barcode height or line width when printing small labels or scanning from a distance.

### Skipping a scan test before printing

Before printing labels in bulk, test the barcode with the scanner or app you plan to use. This helps catch problems with size, contrast, format or incorrect values before producing a full batch.
