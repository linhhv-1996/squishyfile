## Which barcode format should you use?

For most internal labels, **CODE 128** is the safest default because it supports numbers, letters and many common characters. Use **CODE 39** only when you need a simpler barcode with uppercase letters and numbers.

For retail products, use the format that matches your code type: **EAN-13**, **JAN** or **UPC-A**. These formats require fixed-length numeric values, so they will reject text or values with the wrong number of digits.

For cartons and logistics units, **ITF-14** is usually the better choice.

## PNG or SVG: which download format is better?

Choose **PNG** when you need a quick barcode image for documents, labels, spreadsheets or simple printing. Choose **SVG** when you need a scalable vector file that stays sharp at any size, such as for design software or professional label layouts.

## Common barcode mistakes to avoid

### Wrong length for retail codes

EAN-13 and JAN need 13 digits. UPC-A needs 12 digits. EAN-8 needs 8 digits. If your value has a different length, use CODE 128 instead.

### Using letters in numeric-only formats

EAN, UPC, JAN and ITF-14 are numeric formats. If your value contains letters, spaces or symbols, use CODE 128 or CODE 39.

### Making the barcode too small

Very short barcodes can be hard to scan. Increase the height or line width if the barcode will be printed on a small label or scanned from a distance.
