## เครื่องมือสร้างบาร์โค้ดออนไลน์สำหรับสินค้า SKU และสต๊อก

สร้างบาร์โค้ดออนไลน์สำหรับสินค้า สต๊อกสินค้า SKU เลขซีเรียล ฉลากจัดส่ง คลังสินค้า และรหัสใช้งานภายในได้ง่าย ๆ ผ่านเบราว์เซอร์ เครื่องมือ barcode generator นี้ทำงานบนอุปกรณ์ของคุณโดยตรง จึงไม่ต้องติดตั้งโปรแกรมและไม่ต้องอัปโหลดค่าที่กรอกไปยังเซิร์ฟเวอร์

คุณสามารถสร้างบาร์โค้ดทีละอันสำหรับงานด่วน หรือสร้างบาร์โค้ดหลายอันพร้อมกันสำหรับงานฉลากจำนวนมาก จากนั้นดาวน์โหลดเป็นไฟล์ PNG สำหรับใช้งานทั่วไป หรือ SVG สำหรับงานออกแบบและงานพิมพ์ที่ต้องการความคมชัด

---

## รูปแบบบาร์โค้ดที่รองรับ

เครื่องมือนี้ใช้แปลงข้อความหรือตัวเลขให้เป็นบาร์โค้ด 1 มิติ เหมาะสำหรับฉลากสินค้า เอกสาร สต๊อกสินค้า คลังสินค้า งานจัดส่ง และระบบภายใน

| รูปแบบ | เหมาะสำหรับ |
|---|---|
| CODE 128 | SKU, รหัสสต๊อก, เลขซีเรียล, เลขคำสั่งซื้อ และข้อความทั่วไป |
| CODE 39 | รหัสสั้นที่ใช้ตัวอักษรภาษาอังกฤษตัวใหญ่และตัวเลข |
| EAN-13 | รหัสสินค้าค้าปลีก 13 หลัก |
| EAN-8 | รหัสสินค้าขนาดสั้น 8 หลัก |
| UPC-A | รหัสสินค้าสหรัฐฯ 12 หลัก |
| JAN | รหัสสินค้าสำหรับตลาดญี่ปุ่น |
| ITF-14 | กล่องสินค้า บรรจุภัณฑ์ และงานโลจิสติกส์ |

ถ้าไม่แน่ใจว่าจะใช้รูปแบบไหน CODE 128 มักเป็นตัวเลือกที่ยืดหยุ่นที่สุดสำหรับงานภายใน เพราะรองรับทั้งตัวเลข ตัวอักษร และอักขระทั่วไป

---

## วิธีสร้างบาร์โค้ด

1. เลือก **บาร์โค้ดเดี่ยว** หรือ **บาร์โค้ดแบบกลุ่ม**
2. กรอกค่าที่ต้องการ เช่น SKU รหัสสินค้า รหัสสต๊อก เลขซีเรียล หรือรหัสใช้งานภายใน
3. เลือกรูปแบบบาร์โค้ด
4. ปรับความสูง ความหนาเส้น และข้อความที่แสดงใต้บาร์โค้ดตามต้องการ
5. สร้างบาร์โค้ด แล้วดาวน์โหลดเป็น PNG หรือ SVG

โหมดบาร์โค้ดแบบกลุ่มเหมาะสำหรับทำฉลากสินค้า ฉลากคลังสินค้า รหัสสต๊อก เลขซีเรียล หรือบาร์โค้ดจำนวนมากจากรายการข้อมูล

---

## ควรเลือกรูปแบบบาร์โค้ดแบบไหน

เลือก **CODE 128** สำหรับ SKU รหัสภายใน เลขซีเรียล หมายเลขคำสั่งซื้อ รหัสคลังสินค้า และงานติดตามภายใน เพราะรองรับค่าหลายประเภทและใช้งานได้กว้าง

เลือก **CODE 39** สำหรับรหัสสั้นที่ใช้ตัวอักษรภาษาอังกฤษตัวใหญ่และตัวเลข แต่ถ้าต้องการความยืดหยุ่นมากกว่า CODE 128 มักเหมาะกว่า

เลือก **EAN-13**, **UPC-A** หรือ **JAN** เมื่อคุณมีรหัสสินค้าค้าปลีกที่ถูกต้องอยู่แล้ว รูปแบบเหล่านี้ต้องใช้ตัวเลขตามจำนวนหลักที่กำหนด และไม่เหมาะกับข้อความทั่วไป

เลือก **ITF-14** สำหรับกล่องสินค้า บรรจุภัณฑ์ภายนอก หรือหน่วยขนส่งในงานโลจิสติกส์

---

## บาร์โค้ดสินค้าและการจดทะเบียนรหัสอย่างเป็นทางการ

เครื่องมือนี้ใช้สร้างภาพบาร์โค้ดจากค่าที่คุณกรอก แต่ไม่ได้ออกเลขสินค้า ไม่ได้จดทะเบียนรหัส และไม่ได้จัดสรรเลข EAN, UPC, JAN หรือรหัสสินค้าอย่างเป็นทางการ

ถ้าต้องใช้บาร์โค้ดกับร้านค้า มาร์เก็ตเพลส ระบบจัดจำหน่าย หรือซัพพลายเชน คุณควรมีรหัสสินค้าที่ถูกต้องและได้รับการจัดสรรมาก่อน แล้วจึงใช้รูปแบบบาร์โค้ดที่ตรงกับรหัสนั้น

สำหรับงานภายใน เช่น SKU รหัสสต๊อก เลขซีเรียล ฉลากคลังสินค้า หรือรหัสติดตามภายใน การใช้ CODE 128 มักเพียงพอและยืดหยุ่นกว่า

---

## ควรดาวน์โหลดเป็น PNG หรือ SVG

เลือก **PNG** ถ้าต้องการไฟล์รูปภาพที่นำไปใช้ในเอกสาร ตาราง ฉลากทั่วไป ใบงาน หรือพิมพ์แบบง่ายได้ทันที

เลือก **SVG** ถ้าต้องการไฟล์เวกเตอร์ที่ขยายแล้วไม่แตก เหมาะกับงานออกแบบ เลย์เอาต์ฉลาก งานพิมพ์มืออาชีพ หรือไฟล์ที่ต้องการความคมชัดสูง

หลังดาวน์โหลดแล้ว ไม่ควรยืดหรือบีบบาร์โค้ดผิดสัดส่วน เพราะอาจทำให้สแกนยาก แม้จะดูปกติบนหน้าจอก็ตาม

---

## สร้างบาร์โค้ดแบบเป็นส่วนตัวในเบราว์เซอร์

บาร์โค้ดอาจมีข้อมูลภายใน เช่น รหัสสินค้า รหัสสต๊อก เลขซีเรียล หมายเลขคำสั่งซื้อ รหัสลูกค้า หรือรหัสติดตาม เครื่องมือนี้สร้างบาร์โค้ดบนเบราว์เซอร์ของคุณโดยตรง ไม่ต้องสมัครบัญชี และไม่ส่งค่าที่กรอกไปยังเซิร์ฟเวอร์

วิธีนี้เหมาะกับการทำงานกับรหัสภายใน รายการสินค้า ข้อมูลสต๊อก หรือข้อมูลที่ไม่ต้องการส่งไปยังเครื่องมือภายนอก

---

## ข้อผิดพลาดที่พบบ่อย

### ความยาวรหัสไม่ถูกต้อง

EAN-13 และ JAN ต้องใช้ตัวเลข 13 หลัก, UPC-A ต้องใช้ 12 หลัก และ EAN-8 ต้องใช้ 8 หลัก ถ้ารหัสของคุณมีความยาวอื่นหรือมีตัวอักษร ให้ใช้ CODE 128 แทน

### ใส่ตัวอักษรในรูปแบบที่รับเฉพาะตัวเลข

EAN, UPC, JAN และ ITF-14 เป็นรูปแบบที่ใช้ตัวเลข หากต้องการใช้ตัวอักษร ช่องว่าง หรือสัญลักษณ์ ให้เลือก CODE 128 หรือ CODE 39

### เลือกรูปแบบบาร์โค้ดไม่ตรงกับการใช้งาน

SKU รหัสสต๊อก และเลขซีเรียลสำหรับใช้ภายในมักใช้ CODE 128 ได้ดี ส่วนรหัสสินค้าค้าปลีกควรใช้มาตรฐานที่ถูกต้องและรหัสที่ได้รับการจัดสรรอย่างเป็นทางการ

### บาร์โค้ดเล็กเกินไปจนสแกนยาก

ถ้าเส้นบางเกินไป ขนาดเล็กเกินไป หรือมีพื้นที่ว่างรอบบาร์โค้ดน้อย อาจสแกนไม่ติด ควรเพิ่มความสูงหรือความหนาเส้น และทดสอบก่อนพิมพ์จริงจำนวนมาก

### ไม่ทดสอบก่อนพิมพ์จำนวนมาก

ก่อนพิมพ์ฉลากจำนวนมาก ควรทดสอบบาร์โค้ดด้วยสแกนเนอร์หรือแอปที่จะใช้จริง วิธีนี้ช่วยตรวจปัญหาเรื่องขนาด ความคมชัด รูปแบบ การพิมพ์ หรือค่าที่กรอกผิดก่อนผลิตทั้งชุด
