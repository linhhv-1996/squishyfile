# สร้างบาร์โค้ดออนไลน์ฟรี

สร้างบาร์โค้ดสำหรับสินค้า สต๊อกสินค้า SKU เลขซีเรียล ฉลากจัดส่ง และรหัสใช้งานภายในได้ง่าย ๆ ผ่านเบราว์เซอร์ เครื่องมือสร้างบาร์โค้ดนี้ทำงานบนอุปกรณ์ของคุณโดยตรง ข้อมูลที่กรอกจะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์

คุณสามารถสร้างบาร์โค้ดทีละอัน หรือสร้างบาร์โค้ดหลายอันพร้อมกัน แล้วดาวน์โหลดเป็นไฟล์ PNG หรือ SVG ได้

## เครื่องมือนี้สร้างบาร์โค้ดอะไรได้บ้าง

เหมาะสำหรับคำค้นอย่าง สร้างบาร์โค้ด, barcode generator, สร้างบาร์โค้ดฟรี, ทำบาร์โค้ด, สร้างบาร์โค้ดออนไลน์ และสร้างบาร์โค้ดสินค้า

| รูปแบบ | เหมาะสำหรับ |
|---|---|
| CODE 128 | SKU, รหัสสต๊อก, เลขซีเรียล และข้อความทั่วไป |
| CODE 39 | รหัสสั้นที่ใช้ตัวอักษรภาษาอังกฤษตัวใหญ่และตัวเลข |
| EAN-13 | รหัสสินค้าค้าปลีก 13 หลัก |
| EAN-8 | รหัสสินค้าขนาดสั้น 8 หลัก |
| UPC-A | รหัสสินค้าสหรัฐฯ 12 หลัก |
| JAN | รหัสสินค้าสำหรับตลาดญี่ปุ่น |
| ITF-14 | กล่องสินค้า บรรจุภัณฑ์ และงานโลจิสติกส์ |

## วิธีสร้างบาร์โค้ด

1. เลือก **บาร์โค้ดเดี่ยว** หรือ **บาร์โค้ดแบบกลุ่ม**
2. กรอกค่าที่ต้องการ เช่น SKU รหัสสินค้า รหัสสต๊อก หรือเลขซีเรียล
3. เลือกรูปแบบบาร์โค้ด
4. ปรับความสูง ความหนาเส้น และข้อความที่แสดงใต้บาร์โค้ด
5. สร้างบาร์โค้ด แล้วดาวน์โหลดเป็น PNG หรือ SVG

ถ้าต้องสร้างหลายรหัสพร้อมกัน ให้ใช้โหมดแบบกลุ่ม เหมาะสำหรับทำฉลากสินค้า ฉลากคลังสินค้า รหัสสต๊อก หรือบาร์โค้ดจำนวนมากจากรายการข้อมูล

## ควรเลือกรูปแบบบาร์โค้ดแบบไหน

ถ้าไม่แน่ใจ ให้เริ่มจาก **CODE 128** เพราะรองรับตัวเลข ตัวอักษร และอักขระทั่วไป เหมาะกับ SKU รหัสสินค้าในระบบ รหัสคลังสินค้า และเลขซีเรียล

ถ้าเป็นรหัสสินค้าค้าปลีก ให้เลือก **EAN-13**, **UPC-A** หรือ **JAN** ตามชนิดของรหัสที่คุณมี รูปแบบเหล่านี้ต้องใช้ตัวเลขตามจำนวนหลักที่กำหนดเท่านั้น

สำหรับกล่องสินค้า บรรจุภัณฑ์ หรือหน่วยขนส่ง มักใช้ **ITF-14** มากกว่า

## ดาวน์โหลดเป็น PNG หรือ SVG ดี?

เลือก **PNG** ถ้าต้องการไฟล์รูปภาพที่นำไปใช้ในเอกสาร ตาราง ฉลากทั่วไป หรือพิมพ์แบบง่ายได้ทันที

เลือก **SVG** ถ้าต้องการไฟล์เวกเตอร์ที่ขยายแล้วไม่แตก เหมาะกับงานออกแบบ ฉลากมืออาชีพ หรือไฟล์สำหรับพิมพ์ที่ต้องการความคมชัด

## สร้างบาร์โค้ดแบบเป็นส่วนตัวในเบราว์เซอร์

บาร์โค้ดอาจมีข้อมูลภายใน เช่น รหัสสินค้า รหัสสต๊อก เลขซีเรียล หรือรหัสติดตาม เครื่องมือนี้สร้างบาร์โค้ดบนเบราว์เซอร์ของคุณโดยตรง ไม่ต้องสมัครบัญชี และไม่ส่งค่าที่กรอกไปยังเซิร์ฟเวอร์

## ข้อผิดพลาดที่พบบ่อย

### ความยาวรหัสไม่ถูกต้อง

EAN-13 และ JAN ต้องใช้ตัวเลข 13 หลัก, UPC-A ต้องใช้ 12 หลัก และ EAN-8 ต้องใช้ 8 หลัก ถ้ารหัสของคุณมีความยาวอื่นหรือมีตัวอักษร ให้ใช้ CODE 128 แทน

### ใส่ตัวอักษรในรูปแบบที่รับเฉพาะตัวเลข

EAN, UPC, JAN และ ITF-14 เป็นรูปแบบที่ใช้ตัวเลข หากต้องการใช้ตัวอักษร ช่องว่าง หรือสัญลักษณ์ ให้เลือก CODE 128 หรือ CODE 39

### บาร์โค้ดเล็กเกินไปจนสแกนยาก

ถ้าเส้นบางเกินไป ขนาดเล็กเกินไป หรือมีพื้นที่ว่างรอบบาร์โค้ดน้อย อาจสแกนไม่ติด ควรเพิ่มความสูงหรือความหนาเส้น และทดสอบก่อนพิมพ์จริงจำนวนมาก

## คำถามที่พบบ่อย

### เครื่องมือสร้างบาร์โค้ดนี้ใช้ฟรีไหม?

ใช่ คุณสามารถสร้างบาร์โค้ดออนไลน์ได้ฟรี โดยไม่ต้องติดตั้งโปรแกรมและไม่ต้องสมัครบัญชี

### สร้างบาร์โค้ดหลายอันพร้อมกันได้ไหม?

ได้ ใช้โหมดบาร์โค้ดแบบกลุ่มเพื่อสร้างหลายรหัสพร้อมกันและดาวน์โหลดรวมกัน

### ข้อมูลที่กรอกถูกอัปโหลดหรือไม่?

ไม่ ข้อมูลจะถูกใช้เพื่อสร้างบาร์โค้ดในเบราว์เซอร์ของคุณ และไม่ถูกส่งไปยังเซิร์ฟเวอร์

### ใช้สร้างบาร์โค้ดสินค้าได้ไหม?

ได้ หากคุณมีรหัสสินค้าที่ถูกต้องอยู่แล้ว สามารถใช้ EAN-13, UPC-A หรือ JAN เพื่อสร้างภาพบาร์โค้ดได้ แต่เครื่องมือนี้ไม่ได้ออกหรือจดทะเบียนรหัสสินค้าอย่างเป็นทางการ

### ทำไมสร้างบาร์โค้ดไม่ได้?

รูปแบบที่เลือกอาจต้องใช้ตัวเลขเท่านั้นหรือจำนวนหลักเฉพาะ หากเป็น SKU ข้อความ หรือรหัสภายใน ให้ลองเลือก CODE 128
