## 發布前檢查 SNS 字數限制

使用這個 SNS 字數限制檢查工具，可以在發布前確認貼文、說明文字、影片標題、描述、個人簡介或搜尋摘要是否適合目標平台。不同社群平台對文字長度與顯示方式的處理不同。你在編輯器裡看起來剛好的文案，可能在 X 太長、在 Instagram 被截斷，或在 YouTube 標題中讓重點消失。

本頁的重點是平台限制與短文案檢查，不是一般長文分析。若你需要查看完整字元數、去空白字數、位元組、行數與段落數，請使用[字數統計](/zh/character-counter)。若你主要想看英文單字數、文章長度與閱讀時間，請使用[單字計算](/zh/word-counter)。

---

## 這個工具適合檢查哪些文字

SNS 文案通常短、公開，而且使用者很快就會決定要不要繼續看。因此，目標不只是低於最大字數限制，而是讓最先顯示的部分就能清楚傳達重點。

這個工具適合檢查：

- X / Twitter 貼文
- Instagram 貼文說明
- TikTok 說明文字
- YouTube 標題與描述
- Facebook 貼文
- LinkedIn 貼文與個人檔案文字
- 社群個人簡介與短介紹
- 廣告文案、標題與活動短文
- Meta description 與 SEO snippet

如果你正在檢查長篇文章、報告或作文，這頁不是最主要的工具。長文篇幅應該用單字計算或字數統計來看。若你只是要確認表單欄位、標題、資料庫文字或技術限制的字元數，則應使用字數統計頁面。

## 沒有超過上限，不代表顯示效果好

常見問題是把最大字數限制當成目標。但在社群平台上，最大限制只是其中一件事。許多平台會在動態牆、搜尋結果或預覽中先截斷部分內容，使用者必須點擊才能看到完整文字。也就是說，文案沒有超過限制，仍然可能把最重要的訊息藏在「更多」後面。

因此，檢查字數限制時，也要檢查資訊順序。主題、關鍵字、賣點、問題、優惠或行動呼籲，應該盡量放在前段。補充說明、hashtag、連結與次要細節可以放在後面。

修改時不要只從結尾刪字。你需要確認第一句仍然清楚，而且即使文字被截斷，讀者也能先看到核心訊息。

## 為什麼 SNS 需要獨立的字數限制檢查

一般字數統計可以告訴你文字有多長。SNS 字數限制檢查則更重視文字要放在哪裡。這個差異很重要，因為同一段文字在不同平台可能遇到不同問題。

YouTube 標題需要在搜尋結果和推薦列表中仍然清楚。Instagram 說明文字需要在折疊前就吸引注意。X 貼文需要足夠精簡，方便快速閱讀與轉發。個人簡介需要在很少的空間中說明身分或價值。Meta description 則需要在搜尋結果中提早出現主題。

因此，這個頁面應該專注於短文案、社群平台限制與預覽顯示，不應混成一般字元統計、英文單字計算或原稿紙換算。

## 支援 Emoji、hashtag、連結與多語內容

社群文案常常不只是純文字，還會包含 Emoji、hashtag、提及帳號、URL、標點、換行與多種語言。這些元素都會影響實際長度，也可能讓視覺長度和字元數不一致。

這個工具適合中文、英文、日文、泰文、葡萄牙文、Emoji 與混合語言貼文。與其用眼睛估算，不如在發布前貼上文字，確認實際長度和可能的限制風險。

如果你需要計算日文原稿紙 400 字頁數，請使用[原稿紙計算器](/zh/manuscript-counter)。那是不同搜尋意圖，不應和 SNS 字數限制混在一起。

## 更有效率地修改社群文案

先自然寫出想表達的內容，再用工具檢查長度。檢查時可以看三件事：是否超過限制、開頭是否夠清楚、文字是否容易快速掃讀。

如果文字太長，可以依序刪除：

- 重複表達同一件事的句子
- 幫助不大的 hashtag
- 放在重點前面的空泛開場
- 讓 hook 太晚出現的長前言
- 過多 Emoji 或符號
- 可以移到留言、描述或下一則貼文的次要資訊

對影片標題和 meta description 來說，不要只把尾端刪短。要確認關鍵字或主要主題仍然出現在前半段。對貼文說明來說，第一句最好能獨立傳達重點，這樣即使後面被折疊，仍然不會失去主要訊息。

## 依照目的選擇正確工具

當問題是「這段文字適合這個平台或預覽嗎？」時，使用本頁的 SNS 字數限制檢查工具。當問題是「這段文字有多少字元、空白、位元組或行數？」時，使用[字數統計](/zh/character-counter)。當問題是「這篇英文文章或草稿有多少單字？」時，使用[單字計算](/zh/word-counter)。當問題是「這段日文換算成 400 字原稿紙有幾頁？」時，使用[原稿紙計算器](/zh/manuscript-counter)。

把這些用途分開，可以避免用錯指標。好的 SNS 文案不只是短，還要讓重點在被截斷前就出現。
