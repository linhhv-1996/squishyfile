PDF 太大時，可以用 Squishyfile 直接在瀏覽器中壓縮 PDF，讓檔案更適合寄 Email、上傳表單、提交履歷或儲存到雲端。免註冊、免安裝、無浮水印，檔案不需要上傳到伺服器。

## 使用步驟

1. 選擇 PDF，或把檔案拖曳到上傳區。
2. 選擇「平衡壓縮」或「最大壓縮」。
3. 點擊「壓縮 PDF」，並在處理完成前保持分頁開啟。
4. 下載壓縮後的 PDF，提交或分享前先打開檢查內容。

## 適合哪些情況

適合用來縮小履歷、合約、發票、掃描文件、報告、申請表、簡報 PDF、作品集，以及任何因檔案太大而無法寄送或上傳的 PDF。

## 壓縮模式怎麼選

一般文件建議先用 **平衡壓縮**。它會在檔案大小與清晰度之間取得較好的平衡，讓文字、圖片、表格、簽名與掃描頁面仍然容易閱讀。

如果需要壓到 10MB、5MB、2MB 或更小，請改用 **最大壓縮**。壓縮後請先打開檢查文字、印章、簽名、QR Code 和重要圖片是否清楚。

## 哪些 PDF 比較容易變小

掃描檔、照片多的 PDF、截圖、簡報、型錄、證明文件和圖片型文件通常壓縮效果最好。

純文字 PDF、已經最佳化的檔案，或包含大量向量圖形的 PDF，容量可能只會小幅下降。這是正常情況，因為可壓縮的圖片資料較少。

## 在瀏覽器內壓縮 PDF

Squishyfile 使用 WebAssembly 在你的瀏覽器內處理 PDF。檔案不需要傳到雲端伺服器，適合處理履歷、合約、帳單、證件掃描檔與其他含有個人資料的文件。

## 支援的裝置

可在 Windows、Mac、Linux、Chromebook、iPhone、Android 和平板的現代瀏覽器中使用。電腦可拖曳 PDF，手機可從檔案、下載資料夾或雲端硬碟選取文件。
