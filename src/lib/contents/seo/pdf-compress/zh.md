當 PDF 檔案太大，無法作為 Email 附件、上傳表單、提交履歷或儲存到雲端時，可以用 Squishyfile 直接在瀏覽器中壓縮 PDF。使用時不需要註冊帳號，也不需要安裝軟體。

PDF 會透過 WebAssembly 在你的瀏覽器中處理，不必為了壓縮而上傳到外部伺服器。

## 選擇適合的 PDF 壓縮模式

大多數情況下，建議先使用**平衡**模式。它會在檔案大小與閱讀品質之間取得平衡，讓文字、圖片、表格、簽名、印章與掃描頁面仍然清楚可讀。

平衡壓縮適合 Email 附件、履歷、申請文件、合約、發票、報價單、學校或政府系統上傳，以及需要讓對方正常審閱的 PDF。

當檔案大小比畫質更重要時，可以改用**最大壓縮**。例如上傳限制要求 PDF 低於 1MB、2MB、5MB、10MB，或 Email、通訊軟體無法接受太大的附件。

使用最大壓縮後，請打開檔案檢查小字、簽名、印章、QR Code、表格、圖表與重要圖片是否仍然清楚。

## 哪些 PDF 壓縮效果較明顯

PDF 壓縮通常對含有大量圖片或掃描頁面的檔案最有效，因為這類 PDF 有較多影像資料可以最佳化。

常見例子包括手機掃描文件、掃描器或事務機輸出的 PDF、含照片或截圖的文件、從 PowerPoint、Keynote、Google Slides 或 Canva 匯出的簡報、作品集、型錄、報告、收據與證明文件。

掃描 PDF 常常比較大，因為每一頁都像一張圖片。如果原始文件以 300 DPI 或 600 DPI 掃描，對一般螢幕閱讀來說可能包含過多細節。

## 為什麼有些 PDF 壓縮後變化不大

有些 PDF 壓縮後只變小一點，這不一定代表工具失效。原因通常是檔案內沒有太多可再壓縮的圖片資料。

如果 PDF 主要由可選取文字、向量圖形、嵌入字型、表單欄位或文件結構組成，檔案可能本來就已經很精簡。已經壓縮過或重複壓縮多次的 PDF，也通常不會再明顯縮小。

文字型 PDF 的縮小空間通常比掃描 PDF 或圖片型 PDF 少。

## 符合 Email 或上傳限制的做法

先用平衡模式壓縮 PDF。如果仍超過限制，再嘗試最大壓縮。若檔案還是太大，應該調整 PDF 內容，而不是一直重複壓縮同一份檔案。

你可以刪除空白頁或重複頁、從原始 Word 或 PowerPoint 重新輸出較小的 PDF、降低圖片解析度、掃描時使用約 150–200 DPI、不需要彩色時改用灰階，或在平台允許時將大型 PDF 分成多個檔案。

提交前請確認頁面順序、姓名、日期、簽名、印章、QR Code 與表單內容都完整可讀。

## 在瀏覽器中完成的私密 PDF 壓縮

許多線上 PDF 壓縮工具會先把檔案上傳到伺服器再處理。Squishyfile 的壓縮會在瀏覽器中執行，檔案在處理過程中留在你的裝置上。

這種方式適合履歷、合約、發票、報價單、證件影本、財務資料、學校文件或公司內部 PDF。下載壓縮後的檔案後，仍建議妥善保存與分享，特別是曾經移除密碼保護的文件。

## 可在電腦與手機使用

Squishyfile 可在現代瀏覽器中運作，支援 Mac、Windows、iPhone、Android、Chromebook 與平板。電腦上可以拖曳 PDF 到上傳區，手機上可以從檔案 App、下載資料夾或雲端硬碟選擇 PDF。
